# Three.js TextGeometry fonts

These typeface JSON files are vendored from the `three@0.184.0` npm package.
Three.js 0.185 no longer publishes `examples/fonts`, while the text geometry
tool still supports these built-in font choices. Runtime URLs use the Vite
base path so they work locally and on GitHub Pages.
